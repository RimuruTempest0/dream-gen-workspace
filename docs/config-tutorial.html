1配置生图中转站

用于真正生成图片，使用 OpenAI Images 兼容协议。

1.1打开“连接与设置”，点击“添加连接”

1.2填写名称、地址和密钥，然后测试连接

Base URL 不要多写：只填到站点或 API 前缀，不要带 /images/generations 之类的接口路径，也不要带问号参数。如果测试提示地址不对，再按中转站文档，在末尾补上 /v1 重试。

1.3确认认证通过，打开模型下拉框

说明：如果没有显示模型列表，说明该中转站未开放模型查询，直接在“默认模型 ID”里手动填写 gpt-image-2 即可。

1.4选择 gpt-image-2

1.5确认模型已填入，保存连接

1.6确认保存成功

2配置 LLM 供应商

用于智能生图里的链接分析、图片分析和套图规划。这里使用 DeepSeek 的 Anthropic 兼容接口，需要特别修改三项设置（图中橙色框）。

本次要改的三项
设置项默认值改为
单次输出上限（tokens）819232768
模型模式Claude 模型其他模型 · 兼容接入
认证方式x-api-key（默认）Bearer Token

界面里这一项叫“单次输出上限”，限制的是模型一次回复最多能写多少 token，不是输入上限。

2.1点击“添加 LLM 供应商”，先填前四项

入口见 1.6 截图中的第 2 个框。打开后先填写前四项，橙色框是接下来要改的三项（默认值如图）。

2.2把单次输出上限改为 32768，并选择“兼容接入”

为什么调大：一次要写 10 到 12 条完整提示词，8192 在内容较长时可能被截断。可填范围是 256 到 65536，请不要超过你的模型实际支持的上限。

2.3把认证方式改为 Bearer Token

怎么选：服务商文档要求请求头为 Authorization: Bearer 密钥 时选 Bearer Token；要求 x-api-key 时保持默认。

2.4检查三项并保存

可选：如果想核对模型 ID deepseek-flash 是否存在，保存前可以点弹窗左下角的“获取模型”，在出现的下拉框里选择。这一步只查询模型列表，不调用 LLM，不产生 LLM 费用。

2.5验证 Agent 能力

怎么看结果：验证完成后，文本、图片、工具、流式四个标签应当全部变成绿色“通过”。有“未通过”的话，智能生图可能无法使用，需要换模型或检查上面三项设置。如果后面要上传参考图，“图片”必须通过。
费用：验证会发送 4 个小型请求，可能产生少量 LLM 费用，但不会生成商品图片，也不会产生生图费用。

4常见问题

点“获取模型”或“测试连接”没有反应或报错？

先检查 Base URL 是否带了多余路径、密钥是否粘贴完整。测试最多等待 30 秒，可点“取消测试”。网络走代理的，请使用 HTTP_PROXY / HTTPS_PROXY 或 Windows 手动系统代理，修改后重启应用。

认证方式选错了会怎样？

通常表现为 401 或 403，或提示认证失败。回到“编辑 / 获取模型”，把认证方式切换到另一种，再点“获取模型”重试即可，不需要重新填写其他内容。

修改已保存的连接，需要重新输入密钥吗？

不需要。编辑时密钥框显示“已保存 · 留空保留”，留空就沿用原密钥，只有想换密钥时才填写。

配置换电脑或换用户后失效？

密钥由当前 Windows 用户加密，不进入备份。换电脑或用户后，需要重新输入 API Key，其余配置会保留。

改了设置，进行中的任务会受影响吗？

不会。每个任务开始时会冻结当时的供应商配置。连接配置变化后，旧任务提示“连接配置已改变”时，请新建需求。
