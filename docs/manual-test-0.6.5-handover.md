## 四、目前发现的问题（继续记录新问题）

1. **监控页暴露其他线路**：试用期“中转站监控”和“LLM 监控”页面会显示图片线路 2–6 和 LLM 线路 2 的卡片。只有线路名称，没有地址和 Key。
2. **智能生图开始前没有费用确认**：点“开始生成套图”后直接开始，文档预期会先弹出费用确认。
3. **试用用完后仍弹确认框**：工作台仍会弹出“生成 1 张图片？”确认框，被拒绝后这个框也不会关闭。
4. **智能生图草稿丢失**：离开智能生图页面后，需求文字被清空，目标张数恢复为 12。
5. **重装后横幅文案不准**：
   - 重装后素材库是空的，但横幅仍写“之前生成的图片都保留在素材库”；
   - 因上游额度用完而停止时，横幅写“5 张试用图片已用完”，实际只用了 3 张。
6. **重新打包会覆盖旧 ZIP**：同名覆盖，两条交付记录的“打开位置”指向同一个文件。客户目录里还会留下 437 MB 的中间文件 `0.6.5\build-check.zip`。打包时还会弹出一个可见的 PowerShell 窗口。
7. **错误提示不会自动消失**。
8. **激活失败提示少了前缀**：没有“激活失败：”字样（F3）。
9. **PackyCode 不是 Sub2API**：
   - 它的单 Key 额度会被超额使用：…B1Fx 被用到剩余额度 -61844（new-api 计数单位，约 -$0.12）；
   - `https://cf.api.fan/v1/usage` 很可能不是有效的额度查询地址。LLM 线路不查额度，所以不影响试用。
10. **管理员工具（之前发现，未修）**：
    - 能力验证超时时不说明是哪一项卡住；
    - 停用的 Key 不能重新启用；
    - 可以同时运行两个实例。
