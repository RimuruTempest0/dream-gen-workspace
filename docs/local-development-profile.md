# 本机后续开发保留用户配置

用户要求：已在 Portable 0.3.0 配置好生图中转站和 LLM 供应商，后续开发版本继续使用，无需反复输入。

- 本工作区 `.local/profile-source.txt` 记录应沿用的应用目录；其中的 `data-location.txt` 优先于该目录下的 `data`。记录是本机状态，不提交 Git。
- 构建统一使用 `scripts/build.ps1 -Version '版本号'`。默认输出目录跟随版本号；ZIP 打包完成后，本机输出目录自动关联已有数据，并成为下次构建的数据位置来源。
- 现有连接、模型、能力验证和加密凭证由同一数据目录保留，不重新创建连接、不调用中转站、不自动恢复任务。验证时不要提交真实付费生成。
- 不要删除实际数据目录；先通过应用内“更改保存位置”迁移到独立目录。新旧程序共用数据，关闭旧版后再用新版。
- 发布 ZIP 不携带个人配置或目录指针。交付给此用户时，明确提供已关联数据的本机 EXE 路径；若只提供干净 ZIP，须覆盖原应用目录并保留数据。
- `.local/profile-backups` 中的初始快照只包含数据库及加密凭证，用于本机连接配置应急保留，并非包含图片和 Skills 文件的完整应用备份。后续修改以实际数据目录为准。
- 如果本地记录丢失，执行 `scripts/remember-profile.ps1 -ApplicationDirectory '已配置的程序目录'`。不要把 API Key 写进源码、项目记忆、说明、日志或公开压缩包。
