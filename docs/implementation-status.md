# 0.1.0 实现与验证记录

日期：2026-10-11。产品是 Windows portable 独立桌面应用；中转站地址和 API Key 在应用内配置。

## 已交付

- Wails v2 桌面窗口、Go 服务、React 界面、SQLite、本机 DPAPI 密钥保护。
- 多连接、保留 Base URL 前缀、非计费模型查询、模型手填。
- 文生图、multipart 图生图、批量队列、任务参数快照、超时结果未知不自动重发。
- 生成归档、独立补下载、素材预览/导出/归类、项目与模板、本地草稿。
- 备份恢复、备份密钥排除、恢复前保留旧数据、恢复任务显式补充密钥。
- 包内固定 WebView2 155.0.4283.45，已验证微软签名；正式程序无调试端口。

## 验证证据

- `go test ./...` 通过：7 组核心测试，包含两个中转地址、URL/base64、图生图、幂等本地提交、密钥边界、连接快照、5xx 不重发、下载无认证头、恢复与 ZIP 路径校验。
- `go vet ./...`、前端 TypeScript、Vite 构建通过。
- 真实桌面 WebView2/Wails 端到端：4 组通过，使用隔离数据和本机模拟中转服务，详情见 ui-test-results.json。
- 可访问性自动检查无问题，见 accessibility-results.json；基础窄窗口、键盘 Select 与中文界面已检查。自动检查不能替代完整人工 WCAG 认证。
- Premium UI 严格静态审核通过；DESIGN.md 官方 lint 无错误。
- 发布包显式只包含 EXE、运行时、说明与版本校验信息；不包含测试数据、密钥、缓存或源代码工具链。
- 实际 ZIP 解压到新的隔离目录后启动正式 EXE：进程正常运行，7 个 WebView2 子进程来自包内 runtime，SQLite 数据库已创建，9223 调试端口未开放。ZIP 为 312.8 MiB、262 个条目，已检查无 data/cache/secrets。

## 尚未完成外部验收

- 未使用真实中转站 Key 提交付费生成；没有用户提供的连接或测试额度。真实站点的模型、参数、计费和限流须以该站点验证为准。
- 本机是 Windows 11 x64；尚未在独立 Windows 10 或完全无系统运行时的干净虚拟机验收。本机实际使用随包运行时，其进程路径已核对。
- 首版使用同步 Images 兼容协议，不实现幻灵网页专有异步接口，也不承诺任意专有 API 只改 URL 可兼容。
- 恢复仅恢复已归档图片与业务信息；临时结果链接与凭证不进入备份。素材移除保留文件，以保证已有任务引用。
- 默认并发 1，每批最多 200 子任务，参考图最多 4 张且每张 32 MB；这些是本产品限制，不代表所有中转站模型能力。
