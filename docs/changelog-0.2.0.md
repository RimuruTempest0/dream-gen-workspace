# 0.2.0 · Claude Code 与智能生图

新增“智能生图”，在本地工作台输入需求、商品链接和参考图，由内置 Claude Code 分析并规划套图；用户补充信息、修改逐张提示词和参考图后确认生成。分析和方案保存在本地，可从历史记录继续。

- 设置区分“生图中转站”“LLM 中转站”。LLM 支持 Claude 与 Anthropic Messages 兼容接入，模型可手填；文本、图片、工具和流式能力分别验证。验证需确认，可能产生 LLM 费用。
- 内置 Claude Code 2.1.296，固定版本和哈希；无需用户预装 Node、Python 或 Claude Code。密钥由 Go 后端加密保存和用于转发，不写入 Claude 配置、命令参数或前端存储。
- 内置商品分析、Etsy 套图、刺绣规则三个可编辑 Skills，支持导入指令与素材型 Skill 文件夹/ZIP，不执行脚本。
- 逐张编辑、增删、排序、方案版本历史；图片任务复用持久化队列、单图下载、套图 ZIP、补下载和结果未知保护。
- 抓取受阻时在应用内补充资料；不安装浏览器自动化组件。P004、真实尺寸、色卡和名字等规则由用户提供。
- Agent 取消、异常退出和资料迁移保护；备份包含规范化分析记录、方案和 Skills 附件，排除密钥和 Claude 缓存。

## 使用与升级

完整解压 0.2.0 ZIP，保留 `runtime` 和 `agent`。先关闭旧版；覆盖旧应用目录升级时，保留原 `data` 和 `data-location.txt`，建议先在旧版创建备份。单独解压到新目录时为新工作区，可从备份恢复后重配密钥。

在“连接与设置”配置两类中转站；保存 LLM 模型并点击“验证 Agent 能力”。通过所需能力后，到“智能生图”填写需求，分析、补充资料、审阅方案，最后确认生图。

## 验证与限制

本机 Windows 11 真实 Wails 桌面测试11项通过，包含12张套图、Skills、连接分类、原有下载/迁移、资源管理器、窄窗口和无障碍检查。Go 测试包含真实 Claude Code 对接本地模拟 Messages/MCP、图片输入、取消恢复、去重、事务回滚、代理和备份；没有使用真实供应商 Key 或付费接口。

非 Claude 模型兼容性以实际连接验证为准，不转换 OpenAI Chat Completions。网页登录、验证码和动态渲染可能需要手工补资料。未在独立 Windows 10 或干净虚拟机做完整验收。
