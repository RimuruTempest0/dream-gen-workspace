# 管理工具更新记录

管理工具（`ImageWorkbenchAdmin.exe`）从 1.0.0 起有自己的版本号，写在 `internal/admin/version.go`，显示在工具左下角。软件的版本号写在 `wails.json`，说明见 `docs/CHANGELOG.md`；交付包按软件版本命名。只改管理工具时升管理工具的版本，软件版本不变。

## 1.0.0 · 与软件分开版本号；Key 池批量停用和批量删除

- **分开版本号**：管理工具不再占用软件版本号，左下角显示“管理工具 1.0.0”。“生成交付包”里的“软件版本”仍读取 `wails.json`，现在是 0.6.19。
- **样式分开**：管理工具专用的样式移到 `frontend/src/admin/admin.css`，不再进入软件的样式文件。
- **勾选多个 Key**：Key 池“全部 Key”表格每行前加了复选框，表头复选框选择本页，旁边的下拉可以选择全部或清空。勾选后表格上方出现“已选 N 个 Key”和“停用所选”“删除所选”“取消选择”。切换筛选时清空勾选，批量操作只作用于当前筛选显示的 Key。
- **批量停用**：选中的 Key 一起停用（原因记为“手动停用”），已经停用的保留原来的原因。所选里有正在分配给客户的 Key 时按钮不可用，并提示先在客户页撤下。
- **批量删除**：只能删除从未交付过的 Key（可用或手动停用的），从 Key 池和本机加密存储中一起删除，无法恢复，以后可以重新导入。所选里有已分配或交付过（含“曾交付”）的 Key 时按钮不可用，并说明原因：交付过的 Key 的记录用来防止同一个 Key 被重新导入、分给第二位客户，只能停用。
- 后台也做同样检查：所选中任何一个不符合条件时整批都不改动。

这些批量功能曾以软件版本 0.6.20 发布（只改了管理工具）。软件版本已退回 0.6.19；已生成的 0.6.20 交付包仍可使用，只是版本号显示为 0.6.20，并多带一段软件用不到的管理工具样式。软件下一个版本从 0.6.21 开始，避免与这些包重名。

### 验证范围
Go 测试：批量删除选中交付过或已分配的 Key 时整批被拒绝、什么都不改；批量停用选中已分配的 Key 时被拒绝；批量停用保留已停用 Key 的原因；批量删除后 Key 记录和本机密钥文件都被删除；空选择被拒绝。管理员工具桌面测试（隔离数据）：筛选“可用”后全选，包含“曾交付”的 Key 时删除按钮不可用并显示原因，批量停用后列表清空；再筛选“已停用”，勾选从未交付的 Key 批量删除，“曾交付”的 Key 保留；勾选状态下的无障碍检查通过。没有调用真实付费接口。
