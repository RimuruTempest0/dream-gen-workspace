# 0.6.5 实机测试流程（客户版试用 / 激活 + 管理员工具）

> 这份文档交给负责操作电脑的助手（以下称“测试员”）。请按顺序执行，每一步都记录“实际看到的结果”，与“预期”不一致时截图、记录，然后**继续下一步或停下询问**，不要自行修改任何代码或文件来“修好”它。

---

## 0. 测试员必须遵守的规则

1. **不要改动源码目录** `D:\image_workplace` 里的任何文件（管理员工具自己生成的 `release\customers\…` 除外）。
2. **不要删除、移动或打开写入以下位置**：
   - `D:\image_workplace\release\ImageWorkbench-0.3.0\data`（用户真实数据）
   - 任何 `data-location.txt`
   - `%LOCALAPPDATA%\ImageWorkbenchAdmin`（管理员工具的台账与签名密钥）
3. **API Key、备份密码由用户本人输入。** 遇到需要粘贴 Key 或设置密码的步骤，停下来请用户操作，不要在对话里索取或复述 Key。
4. **会产生费用的步骤**已标注 💰。整个流程预计生成约 7–8 张图、少量 LLM 请求，合计约 $0.2–0.3。除标注的步骤外不要点“生成”。每次生图只生成 **1 张**（智能生图那一步除外，见 C4）。
5. 上游后台（幻灵、1 Route 网页）里改额度的操作，请用户本人做，或在用户已登录的情况下由用户明确同意后再做。
6. 测试用的客户包解压到 **`D:\IW测试\`** 下，不要放到 `D:\image_workplace` 里。

## 1. 测试前准备（用户本人完成）

### 1.1 测试专用的 8 个 Key
在上游后台**新建 8 个只用于测试的 Key**（不要用准备发给客户的 Key），并记下各自的末 4 位：

| 上游 | 类型 | 数量 | 在管理员工具中的用途 |
| --- | --- | --- | --- |
| 幻灵 HuanlingAI | 生图（分组能用 `gpt-image-2`） | 3 | 主用 2、备用 1 |
| 1 Route | 生图（`gpt-image-2`） | 3 | 主用 1、备用 2 |
| PackyCode | LLM（模型 `deepseek-flash`，多模态） | 2 | 主用 1、备用 1 |

> 管理员工具按 Key 去重，同一个 Key 不能既当生图 Key 又当 LLM Key，所以幻灵的生图和 LLM 要分别建 Key。

### 1.2 先在上游设好试用额度（单 Key 额度，单位 USD）
不要设为 0（Sub2API 里 0 可能表示“不限额”）。

| Key | 初始额度 |
| --- | --- |
| 幻灵生图 Key A（将分配到“图片线路 1”） | $0.30 |
| PackyCode LLM 主用 Key（将分配到“LLM 线路 1”） | $0.20 |
| 其余 6 个 Key | $0.05 |

### 1.3 其他
- 确认 1 Route 和幻灵用的生图模型 ID **完全相同**（都是 `gpt-image-2`）。不同的话，激活后无法在两家之间自动切换。
- 关闭正在运行的 ImageWorkbench 和 ImageWorkbenchAdmin。
- 新建空文件夹 `D:\IW测试`。

## B. 管理员工具：配置与生成交付包

打开 `D:\image_workplace\release\admin\ImageWorkbenchAdmin.exe`。

### B1. 设置与签名密钥
| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| B1.1 | 左侧进入“设置与签名密钥” | 显示公钥指纹（16 位）和“请务必备份签名密钥”的提醒 |
| B1.2 | “源码目录”应为 `D:\image_workplace`；若显示“未设置”，点“选择源码目录”选它 | 路径显示为 `D:\image_workplace` |
| B1.3 | 记下“管理工具数据”路径 | 位于 `…\AppData\Local\ImageWorkbenchAdmin` |
| B1.4 | **（用户本人）** 输入两次备份密码（≥10 位）→“导出加密备份”→ 保存到 U 盘或其他位置 | 提示导出成功，生成备份文件 |
| B1.5 | 只输入一次密码、或两次不一致 | 按钮不可点；不一致时提示“两次输入的密码不一致” |

### B2. 添加上游（Key 池 → 上游 → 添加上游）
依次添加 3 个：

| 字段 | 幻灵图片 | 1Route图片 | PackyCode LLM |
| --- | --- | --- | --- |
| 名称 | `幻灵图片` | `1Route图片` | `PackyCode LLM` |
| 类型 | 图片中转站 | 图片中转站 | LLM 供应商 |
| API 地址 | `https://ai.huanling.icu/v1` | `https://image-api.1route.dev/v1` | `https://cf.api.fan/v1` |
| 模型 | `gpt-image-2` | `gpt-image-2` | `deepseek-flash` |
| 可以给单个 Key 设硬额度 | ✅ 勾选 | ✅ 勾选 | ✅ 勾选 |
| 剩余额度查询地址 | 留空 | `https://api.1route.dev/v1/usage` | 留空（试用只查图片线路 1，LLM 不查） |
| 后台地址 | 幻灵的 Key 管理页（可选） | 1 Route 的 Key 管理页（可选） | PackyCode 的 Key 管理页（可选） |
| 接入方式 / 认证方式 / 输出上限 | — | — | 兼容接入 / Bearer / 8192 |

预期：
- 上游表格出现 3 行，“单 Key 额度”列都是绿色“支持”。
- 点“编辑”幻灵图片：查询地址已自动补成 `https://ai.huanling.icu/v1/usage`。
- 额外检查：添加一个上游时**不勾选**“单 Key 额度”，然后在“导入 Key”里选中它 → 出现黄色提醒“这个上游不能限制单个 Key”。检查完把这个上游删掉（没有 Key 的上游可以删除）。

### B3. 导入 Key（**用户本人粘贴 Key**）
在“导入 Key”区块，每次选择上游和用途，粘贴对应的 Key（每行一个），额度备注写“测试”，点“导入”：

1. 幻灵图片 · 主用 · 2 个
2. 幻灵图片 · 备用 · 1 个
3. 1Route图片 · 主用 · 1 个
4. 1Route图片 · 备用 · 2 个
5. PackyCode LLM · 主用 · 1 个
6. PackyCode LLM · 备用 · 1 个

预期：
- 每次提示“已导入 N 个”。顶部“可用”计数最终为：图片 主用 3 / 备用 3；LLM 主用 1 / 备用 1。
- **重复检查**：再导入一次第 1 步里的任意一个 Key → 提示“已导入 0 个”，“跳过重复 1 个”。
- “全部 Key”表只显示 Key 末 4 位，不显示完整 Key。

### B4. 💰 LLM 能力验证（少量费用）
| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| B4.1 | “全部 Key”表中，对PackyCode LLM 的主用 Key 点“验证能力” | 弹出费用确认框，说明会发 4 个很短的请求 |
| B4.2 | 点“验证（产生少量费用）” | 提示“能力验证通过”，“能力”列变为“已验证” |
| B4.3 | 对备用 LLM Key 重复 | 同上 |

> **如果验证失败**：记录完整报错，**停止测试**并告诉用户。常见原因是模型 ID 不对（应为 `deepseek-flash`；`deepseek-v4-flash` 不支持图片，图片检查会卡住），或该上游不支持 Anthropic Messages 协议（`/v1/messages`）。

## I. 收尾

1. 关闭客户版和管理员工具。
2. **（用户本人）** 在幻灵、1 Route 后台**停用或删除**这 8 个测试 Key。
3. `D:\IW测试` 可以整个删除（只是测试副本）。
4. 管理员工具里“内部测试”这位客户和这 8 个 Key 会留在台账里（工具不提供删除客户），这样这些 Key 也不会再被分给真实客户。
5. 本机为这个测试软件标识留下的试用/激活记录（`%APPDATA%\ImageWorkbench\licenses\<标识>.bin` 和注册表 `HKCU\Software\ImageWorkbench\Licenses\<标识>`）可以保留，不影响任何其他软件包；如要清理，**只删除这个测试标识对应的那一项**。
6. **不要**删除 `D:\image_workplace\release\ImageWorkbench-0.3.0\data`、`%LOCALAPPDATA%\ImageWorkbenchAdmin`。
