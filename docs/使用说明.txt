生图工作台 · Portable

完整解压压缩包，双击 ImageWorkbench.exe。
请保留 EXE 同级 runtime、agent 文件夹和 product-browser.exe，分别是界面运行组件、内置 Claude Code 和商品页浏览器。
升级先关闭旧版、创建备份；覆盖原应用目录时保留 data 和 data-location.txt。

首次配置：
连接与设置 → 添加连接 → 填写名称、Base URL、API Key、默认模型。
Base URL 填写 API 前缀，例如 https://example.com/v1。
测试连接只获取模型列表，不生成图片。
测试连接先检查地址和密钥，等待时显示提示，最多30秒；可点击“取消测试”。
网络请求优先使用显式 HTTP_PROXY / HTTPS_PROXY 配置；普通启动使用 Windows 已开启的手动系统代理。
模型查询、生图和图片下载使用相同网络规则。修改系统代理后请重启应用。
不自动修改 Windows 代理；仅配置 PAC 的环境暂不支持自动发现。
未开放模型列表的中转站可以手动填写模型 ID。

生成图片：
工作台选择连接，填写提示词，点击生成。
添加参考图后转为图生图。批量模式每行一条提示词。
尺寸和质量请按照所用模型能力填写；auto 不发送该参数。
图片会自动保存到本地素材库，导出原图可选择保存位置。
最近生成按一次提交的批次展示，每张已保存图片提供“下载图片”。
同一批次可点击“下载套图”保存为一个 ZIP，包含全部已保存原图，不受预览数量限制。
尚未全部完成时按钮显示“下载已完成图片”，未生成或保存失败的图片不在 ZIP 中。
取消保存对话框不会创建文件；下载不会重新调用生图接口。

密钥与数据：
密钥由当前 Windows 用户加密，不进入备份。
换电脑或用户后重新输入 API Key。
data 保存业务数据，cache 是可重建缓存。
连接与设置 → 打开数据位置：在资源管理器查看当前目录。
连接与设置 → 更改保存位置：选择空文件夹，确认迁移并使用。
现有图片、任务、项目、模板和本机加密密钥一起迁移，原目录保留。
新位置立即生效，普通启动会记住该位置；有活动或等待任务时需先结束/停止。
备份包含项目、模板、任务与图片，不包含密钥及临时结果链接。
恢复前会保留原数据目录，尚未提交的任务需配置密钥后手动恢复。

超时及退出：
提交期间显示连接、等待中转站、接收结果等实际阶段及等待时长。
超过两分钟的慢响应提示不会取消请求或自动重试。
任务详情持续刷新，显示响应状态和平台请求标识（如平台提供）。
生成中最小化可继续执行；关闭时有任务会提示。
结果未知表示平台可能已生成或扣费，请先核对平台记录。
补下载不会重新生成，重新生成是新的可能计费请求。

此版本支持 OpenAI Images 兼容中转协议。中转站专有网页接口不一定兼容。
完整包无需另外安装运行时；固定运行时随新版本完整包一起更新。

智能生图（0.3.0）：
在设置配置LLM供应商及生图连接，保存并验证模型必要能力。
智能生图输入完整制作指令、链接和参考素材，默认12张、1:1。
供应商、模型、项目和图片参数位于“更多设置”，全部下拉选择并记住上次选择；模型列表来自所选中转站（只查询，不计费），尺寸随画面比例自动匹配。
点击“开始生成套图”即授权本次LLM与生图服务调用，可能产生费用。
资料缺失时集中补充，全部必要资料齐全后由后台自动生成整套。
客户只查看制作进度与图片，不必查看分析、规则或编辑确认提示词。
抓取受阻可上传商品原图或粘贴商品描述，技术详情在日志中。
图片支持单张下载、整套ZIP以及部分完成下载。
点击套图里的任意图片可查看原图大图：上一张/下一张或键盘 ← → 切换，点击图片切换适应窗口/实际大小，可直接下载原图或优化。
已完成的图片可点“优化”，写下想怎么调整，以该图为底图重新生成一次（可能产生费用）；旧版本保留在“之前的版本”中，整套下载只包含当前版本。
智能生图的套图只在智能生图页面显示，不出现在生图工作台的“最近生成”。
更多设置 → 同时生成张数：选择同时向中转站发送几张图的请求（1–8 张，默认 3 张）。生成中也可调整，立即生效；调低时已在生成的图片会继续完成。中转站可能限制并发，出现大量失败或 HTTP 429 时请调低。
取消/异常退出/恢复后不自动重新分析或提交，待生成图片可明确恢复。
结果未知不自动重发，补下载不重新生图；重新生成会产生新请求。
旧需求可明确“继续制作”，已提交批次不会重复创建。
Skills在设置启停和管理，只执行指令与素材，运行时冻结版本。
内置“P004 生图规则”默认启用：欧美模特、刺绣不超过 25 cm 且各图一致、卫衣胸前刺绣按衣服中轴居中、袖口刺绣只在画面右侧袖子且文字平行袖口接缝、全图清晰不虚化；启用时后台会把这些规则附加到每张图的提示词。修改或停用该技能后不再附加。

商品页浏览器（0.3.1）：
商品网站拦截直接读取时，应用在后台用内置浏览器打开商品页，通常十几秒内完成。
如出现“完成验证后将自动继续”窗口，请在窗口中完成网站验证，完成后自动继续。
关闭该窗口或超过3分钟，会改为提示上传商品图片或粘贴描述。
浏览器 Cookie 保存在当前数据目录，不进入备份；连接与设置 → 清除商品页浏览器数据 可删除。
浏览器只读取页面，Claude 不能操作它；不保证所有网站都能读取。

日志（0.2.2）：
左侧“日志”可查看应用、连接验证、智能分析与生图任务的阶段和错误。
支持日志级别、来源、关键词和关联 ID 筛选，查看详情、分页与手动/自动刷新。
日志保留最近5000条，随当前数据目录迁移和备份保留；密钥在写入前脱敏。
从此版本开始记录，不补造旧任务日志，旧任务可在任务中心查看。
