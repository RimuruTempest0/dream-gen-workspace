# Portable 生图桌面应用开发计划

## 1. 产品目标与范围

交付 Windows 10/11 x64 独立桌面应用：解压后双击 EXE 打开应用窗口，在应用内填写 Base URL 和 API Key、选择模型即可使用。采用 Wails v2 + React + TypeScript + Go + SQLite，随包携带 WebView2 固定运行时。

幻灵仅作为中转站接入验证的一个例子，不作为产品固定供应商。连接地址、密钥、模型和能力均由连接配置与协议适配层管理，不硬编码幻灵域名、分组、模型列表、价格或网页任务接口。

第一版包含文生图、图生图、多提示词批量生成、任务中心、素材库、项目、提示词模板、备份与恢复。采用浅色中文界面；任务、参考图、结果和项目资料在本地保存。首版不包含多人账号、云同步、CSV 导入、自动更新和详情页自动排版。

## 2. 桌面架构与连接配置

### 桌面架构

| 部分 | 选型与职责 |
|---|---|
| 桌面窗口 | Wails v2，标准 Windows 标题栏、最小化、最大化、关闭与单实例激活 |
| 前端 | React、TypeScript、Vite、Ant Design、React Router、TanStack Query |
| 前后端通信 | Wails 类型化方法绑定；任务事件通知刷新，数据库查询提供真实状态 |
| 后端 | Go 模块化单体：连接、协议适配、任务调度、素材、项目、模板、备份 |
| 数据库 | SQLite，使用 modernc.org/sqlite；持久化任务队列，默认并发 1 |
| 文件与密钥 | 本地图片目录；Windows DPAPI 加密 API Key，换电脑重新输入 |
| 便携运行时 | 包内 x64 WebView2 Fixed Version，界面缓存也放在便携包内 |

数据流：应用内 React 界面 → Wails 调用桥 → Go 服务 → 用户配置的中转站 → 本地归档。业务功能不依赖外部浏览器、本地网页入口或浏览器 Cookie。

便携包包含 ImageWorkbench.exe、runtime、data、cache 与使用说明。运行时路径与数据路径根据 EXE 位置解析，不使用当前工作目录。数据目录不可写时提供原生目录选择。缓存可重建，不进入备份。运行时解压后超过 250 MB，随应用发布维护版本。

Windows 10 上验证并处理固定运行时要求的目录读取权限；失败时显示明确原因，不静默安装系统组件。首版支持本地可写目录与中文/空格路径，不支持网络共享路径。

### 应用内连接设置

- 设置页提供连接名称、Base URL、API Key、默认模型，以及“测试连接”“获取模型”“保存”操作。支持多个连接，生图工作台选择活动连接。
- 首版默认采用 OpenAI Images 兼容协议。用户填写 API 前缀地址，例如 https://example.com/v1；不固定域名，不擅自重复追加 /v1，也不通过猜测多个路径自动提交付费请求。
- 支持合法 HTTP/HTTPS 地址；默认示例使用 HTTPS。保留用户填写的路径前缀，明确拒绝 query、fragment 和 URL 内嵌凭证。允许 localhost 中转服务。
- API Key 输入框默认遮罩，提供临时显示；“保存”才持久化。编辑已保存连接时，空密钥表示保留原值，清除使用单独操作，遮罩占位符不当成新密钥保存。
- 模型从对应连接查询；站点不开放模型列表时允许手动填写模型 ID。连接测试不生成图片，分别显示认证、模型列表和协议检查结果，不把模型查询成功当成生图验证成功。
- 首版实现通用 Images 文生图/图生图适配器，支持结果 URL 与 base64。接口字段和参考图上传方式通过接入验证固定，未经验证的模型参数不自动发送。
- 非兼容协议需另加协议适配器，不承诺任意中转站仅改 URL 即可使用。高级设置展示协议类型；常规设置流程保持 Base URL、Key 和模型三个主要输入。
- 幻灵网页的 image-playground/batches 路径不作为通用协议默认值；只有验证其 Key 独立认证与完整协议后，才可作为单独扩展适配器，首版不依赖它们。

## 3. 界面与业务接口

界面由生图工作台、任务中心、素材库、项目与模板、设置五组页面组成。工作台集中展示提示词/参考图、预览、模型参数和当前任务。使用原生文件选择与导出对话框，支持图片拖入；确认和错误反馈采用统一应用内组件。

建立 DESIGN.md 和 UX-CONTRACT.md。浅灰背景 #F5F6F8、白色面板 #FFFFFF、深灰文字 #182230、蓝色主操作 #245BDB、绿色成功 #18794E、红色错误 #B42318；中文系统字体、14px 正文、20px 标题。覆盖加载、空白、失败、断网、部分成功、键盘操作和高 DPI。

通过 Wails 暴露 ConnectionService、TaskService、AssetService、ProjectService、TemplateService、BackupService。连接能力包含保存、测试、模型查询；任务能力包含提交批次、分页查询、停止待执行项、重新生成与补下载。

任务提交仅传连接 ID、模型 ID、提示词、参考图 ID 和参数；密钥只由 Go 解密后用于上游请求。事件仅用于通知，页面启动和重新进入时从数据库查询。

连接修改不改变已有任务的目标地址：提交时冻结连接的 Base URL、协议、模型与参数快照，任务绑定不可变的加密凭证版本。新任务使用新配置；显式删除凭证时警告其对待执行/恢复任务的影响。快照和日志不保存明文密钥。

## 4. 任务、数据与开发顺序

### 可靠性规则

- 多条提示词 × 张数展开为独立子任务，逐个执行，允许部分成功；批量确认展示总任务数。
- 状态区分等待、提交中、生成中、下载中、完成、失败、结果未知、已取消。同步协议不显示虚构的上游进度。
- 请求前持久化参数和稳定请求标识。超时或崩溃后先核对；没有查询能力时标记结果未知，不自动重发。只有验证过幂等语义后才启用生成请求自动重试。
- 停止批次取消尚未提交的任务，已提交任务按协议能力处理。补下载与重新生成分开，重新生成提示可能再次计费。
- 图片立即下载到临时文件再原子归档。下载失败不触发重新生成；下载到第三方结果域名时不携带中转站 API Key，重定向不得泄漏认证头。
- 没有活动任务时关闭窗口直接退出；有活动任务时提供继续运行或退出并暂停本地执行，并说明上游已提交任务可能继续。最小化继续执行。
- 备份暂停调度，取得一致的数据库和文件快照；排除密钥、缓存、临时下载与认证信息。恢复先校验，保留原数据，换电脑重新配置连接密钥。
- 数据库升级前自动备份；日志脱敏，磁盘不足、文件损坏和错误认证提供可操作反馈。

### 开发阶段

| 阶段 | 内容与完成标准 |
|---|---|
| ① 桌面便携验证 | 打出最小 Wails + React 包，在没有系统 WebView2 的环境解压后打开窗口 |
| ② 通用接入验证 | 应用内填写 Base URL/Key、查询或手动配置模型，验证文生图/图生图请求、返回和下载；幻灵仅作一个真实样例 |
| ③ 最小后端 | SQLite、连接与凭证管理、通用适配器、持久化队列、worker、图片归档和恢复 |
| ④ 首个桌面闭环 | 应用内配置 → 生成 → 预览 → 原生文件导出；完成真实 EXE 验证 |
| ⑤ 完整工作台 | 批量、任务中心、素材库、项目、模板、参考图交互 |
| ⑥ 数据与发布 | 备份恢复、升级、故障恢复、高 DPI、干净 Windows 环境验收，交付 ZIP 与说明 |

先验证便携桌面封装与通用协议，再完成最小后端和真实前端闭环。付费接入测试在明确测试额度后执行；故障和多连接测试使用模拟中转站。

## 5. 测试与最终验收

- 通用连接测试：至少两个不同 Base URL 的模拟兼容服务，切换连接、路径前缀、Key 更新、模型手填、认证失败与不兼容协议提示；验证不存在硬编码幻灵依赖。
- 接入测试：文生图、图生图、URL/base64 结果、429、5xx、超时、参考图上传、结果链接过期与下载认证边界。
- 任务测试：批次部分失败、重复点击、停止队列、活动任务退出、异常重启、连接修改时任务快照保持原目标、未知结果不自动重发。
- 数据与桌面测试：中文/空格路径、只读目录处理、磁盘不足、备份恢复、密钥迁移提示、单实例、高 DPI、键盘、原生导入导出。
- 发布检查：Go 测试、前端类型检查与构建、设计契约检查、便携包端到端验收；验证 Windows 10/11 x64 缺少系统运行时也能启动。

验收要求：双击独立窗口；Base URL/Key/模型全部在应用内配置；协议兼容的中转站可换连接使用；生成图片与参数本地保存；重启不丢历史且不自动重复付费；备份可搬迁且无密钥；日志和前端持久化存储没有明文 Key。
