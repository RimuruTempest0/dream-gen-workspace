# 0.1.5 功能与按钮修复

- 最近生成按提交批次展示。每张已保存图片可选择路径下载原图；同批次可一次保存 ZIP，包含全部已保存原图，不受页面仅预览 6 个任务的限制。部分完成时明确标注下载范围。
- 图片与套图保存使用相同的原生路径选择及反馈。取消不生成文件；写入失败可重试；原图丢失会报错，不静默跳过或破坏已有 ZIP。下载不发起生图请求。
- 打开数据位置改用 Windows ShellExecute 的正常可见窗口，修复隐藏窗口启动 Explorer 的问题；失败提供错误反馈。
- 新建连接测试校验地址和密钥。模型查询以完整 JSON 为响应边界，不等待 HTTP 流结束；保留30秒超时，支持取消和迟到结果隔离。已保存连接可留空密钥测试，认证错误可见且脱敏。
- 保持 0.1.4 的 Windows 系统代理支持。悬停文字颜色使用现有品牌色，保证白底对比度。
