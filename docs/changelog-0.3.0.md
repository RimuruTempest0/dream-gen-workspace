# 0.3.0 · 自动完成智能套图

智能生图改为“输入需求 → 开始生成 → 必要时补充资料 → 自动完成 → 下载”。客户不再查看商品分析、规则、Skills执行、逐张提示词或方案版本，也无需再次确认方案。

- 保留制作需求、链接和参考素材；张数/比例默认12张、1:1，供应商及参数移入更多设置并记住选择。单链接自动提取，多个链接由用户选择。
- 点击开始授权本次LLM与生图请求，显示张数、模型及费用提示。后台冻结连接、模型和参数，恰好生成授权张数，每项一张。
- 必要资料全部齐全后才生成。可选字体不强制提供；真实尺寸、色卡、名字、指定字体、填充色、P004和外观冲突按任务实际需要补充，不编造。商品链接受阻时上传原图或粘贴描述。
- Go负责自动提交，要求Claude本轮正常结束、保存新的完整有效方案、无未解决的必要问题；失败、取消、过量方案、参数修改和旧方案不会触发生图。开始/继续请求持久化去重，批次与任务事务保存。
- 进度和结果使用真实状态与时间，部分完成可下载。单图、套图ZIP、补下载和明确重新生成保留。日志显示脱敏技术详情，客户页面使用简短反馈。
- 重启后自动套图的未提交图片暂停，可明确恢复。取消、异常和备份恢复不自动重新分析或提交；结果未知不自动重发。旧需求需明确继续，已有批次不重复创建。
- 内部资料、方案和Skill版本仍保存；备份排除两类连接快照密钥及执行就绪标记。未编辑内置Etsy技能更新为自动流程，用户编辑版本保留。

## 升级

关闭旧版，完整解压便携包升级程序及运行组件。保留data、data-location.txt和自选数据目录。Claude Code仍为固定2.1.296，无需预装Node、Python或Claude Code。

## 验证范围

使用本地模拟接口、可控Agent与真实内置Claude Code验证；没有调用用户供应商Key或付费接口。模拟测试不代表所有线上模型均兼容，实际能力仍以用户配置后的验证结果为准；没有在独立Windows 10或干净虚拟机做验收。
