# 0.2.2 · 日志页面

左侧导航新增“日志”，集中显示应用启动、连接/Agent 能力验证、智能分析与生图任务的真实阶段及错误。最新记录优先，支持按级别、来源、关键词或关联 ID 筛选，每页50条；可打开详情、手动刷新、启停默认每3秒的自动刷新。

日志保存在当前数据目录的 SQLite 中，保留最近5000条，随迁移、备份与恢复保留。已有数据库自动创建日志表，不改变原有连接、密钥或任务。日志从此版本开始记录，旧任务详情仍在任务中心。

只记录阶段与错误摘要，不记录提示词、请求体、图片数据、临时图片结果链接或 Agent 原始思考。写入前移除已保存密钥、认证值、URL 凭证和查询参数。重复状态不会反复记录，日志写入失败不会重发或回滚生图任务。

验证覆盖日志脱敏、筛选分页、持久化、5000条上限、旧数据库升级和迁移备份；桌面测试覆盖真实连接错误、详情、空态、暂停/手动刷新、分页及筛选复位、窄窗口和无障碍。测试均使用本地模拟服务，无付费 API 调用。

关闭旧版后完整解压新便携包并升级，保留 `data`、`data-location.txt` 和自选数据目录。继续沿用 Claude Code 2.1.296，包含0.2.1的 LLM 供应商文案和 DeepSeek 修复。

验收结果：Go核心测试33项、vet、前端类型与构建、格式及严格UI检查通过；13项桌面测试通过。发布包完整性及程序/Claude哈希已校验。
