# 销售前验收清单（I2）

这份清单由你亲自执行：会用到真实 Key、真实付费生成和一台干净的虚拟机，开发会话不代做。每一项写了步骤和预期结果，逐项打勾；不符合预期的，在“日志 → 导出诊断包”后把 ZIP 和现象一起记下来。

> 支持范围：软件仅支持 **Windows 11 x64**（Windows 10 不在支持范围内）。验收在一台干净的 Windows 11 x64 虚拟机上进行。

## 准备

- [ ] 一台**全新安装**的 Windows 11 x64 虚拟机（没有装过 Node、Go、WebView2 开发工具；可以用系统自带的 Edge），本机用户名包含中文更好（检验中文路径）。
- [ ] 在管理工具（1.1.0 起）里新建一位“验收客户”：分配图片线路 1、一条备用图片线路、LLM 线路 1 的真实 Key；把每个 Key 的上游额度设为**刚好够试用**（例如 3 张图的金额）；有效期设为**明天**。
- [ ] 生成交付包，记下 ZIP 的 SHA-256；把 ZIP 复制到虚拟机的 `C:\Users\<用户>\Desktop\生图 测试\`（路径含中文和空格）。
- [ ] 准备一个真实商品链接（Etsy / Amazon / Walmart 各一个更好）和 2 张参考图。

## A. 安装与首次启动

| # | 步骤 | 预期结果 |
|---|---|---|
| A1 | 右键 ZIP → 全部解压，双击 `ImageWorkbench.exe` | 不需要安装任何东西就打开主界面；没有 SmartScreen 以外的报错（未签名时 SmartScreen 会提示“未知发布者”，记下来，见阶段 8） |
| A2 | 看左下角 | 显示“试用剩余 N / N 张”和版本号 |
| A3 | 打开“连接与设置” | 只显示线路名称（图片线路 1、LLM 线路 1），**没有**地址和 Key，不能添加或修改 |
| A4 | “连接与设置 → 授权” | 显示软件标识、“试用中”、有效期（明天的日期） |
| A5 | 设置 → Claude Code 与 Skills | 内置技能只有名称、说明和开关，没有“编辑”，看不到正文 |

## B. 真实付费生成（会产生费用）

| # | 步骤 | 预期结果 |
|---|---|---|
| B1 | 生图工作台：写一句提示词，1 张，点生成 | 30–120 秒内出图，自动进素材库；试用剩余减 1 |
| B2 | 加 1 张参考图再生成 1 张（图生图） | 正常出图 |
| B3 | 智能生图：贴商品链接，张数改为 3（试用额度内），点“开始生成套图” | 读到商品页（遇到人机验证会弹窗，手动过一次）；缺资料时提问；补齐后自动生成 3 张；“运行详情”和“LLM 监控”有记录 |
| B4 | 生成前看“开始生成套图”上方 | 第二次起显示每张用时、分析 tokens 的参考；额度能读取时显示图片费用参考 |
| B5 | 试用用完后再提交 | 提示“试用额度已用完”，不发请求 |
| B6 | 到上游后台核对 | 扣费次数与“中转站监控”的成功/结果未知次数一致；没有多扣 |

## C. 激活与续费

| # | 步骤 | 预期结果 |
|---|---|---|
| C1 | 在上游后台调高额度；管理工具“已收款并调高额度”；把激活码输入软件 | 显示“已激活”，出现备用线路；试用期的图片都还在 |
| C2 | 激活后生成 1 张 | 正常出图；“授权”里显示图片线路 1 的剩余额度 |
| C3 | 关掉软件，把虚拟机时间调到有效期之后，再打开 | 显示“授权已到期”，不能生成；素材库、下载、导出正常 |
| C4 | 把时间调回正确时间 | 若仍在有效期内，恢复可用；若比上次使用时间早一小时以上，提示把时间改回来 |
| C5 | 管理工具把有效期改到一年后 →“生成续费授权文件”→ 拷到虚拟机 →“导入授权文件” | 立即恢复生成，图片和激活状态保留，程序目录多了 `customer.dat.bak` |

## D. 稳定性与恢复

| # | 步骤 | 预期结果 |
|---|---|---|
| D1 | 生成中断网 10 秒再恢复 | 图片标“结果未知”并按规则自动重新生成一次（可能多扣一次，核对上游） |
| D2 | 生成中直接关闭窗口 → 选择退出 → 再打开 | 未提交的图片暂停、不计费，可手动恢复 |
| D3 | 连接与设置 → 更改保存位置 → 选一个空文件夹 | 图片、任务、模板迁移；新位置立即生效 |
| D4 | 创建备份 → 恢复备份 | 恢复后图片和任务都在；需要时重新输入密钥（客户版线路由授权文件管理） |
| D5 | 日志 → 导出诊断包，解压查看 | 有 summary.json、logs.txt、failures.json；搜不到 Key、激活码、线路地址、提示词 |
