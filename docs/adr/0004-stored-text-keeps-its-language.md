# 已存下的文字保持写入时的语言

2026-11-18，已采纳。适用于大众版的多语言（0.8.0 起）。

## 背景

大众版要支持五种界面语言（中文、英语、越南语、日语、韩语），顾客可以随时切换。软件里有一类文字是在事情发生时写下来、之后再显示的：日志、任务的错误说明、样板核对意见、AI 写给顾客的提问和判断说明等。

切换界面语言后，这些旧文字该怎么显示，有两种做法：

- 存“文字编号和参数”，每次显示时按当前界面语言重新拼出句子；
- 存写入时就拼好的句子，以后原样显示。

## 决定

已存下的文字保持写入时的语言，不随界面语言切换而重新翻译。切换后新产生的文字按新的界面语言写。

## 为什么

- 这类文字有相当一部分是 AI 模型自己写的（核对意见、提问、判断理由），本来就没有“编号”可言，事后翻译只能再调一次模型，既花钱又可能改变原意。
- 软件自己写的那部分（日志、错误说明）要改成“编号 + 参数”，需要改动全部写入点和存储格式，并迁移已有记录；而顾客切换界面语言通常只发生在刚开始使用时，收益很小。

## 后果

- 切换过界面语言的顾客，会在日志和旧任务里看到两种语言混在一起。这是预期行为，不是缺陷。
- 以后若要改成按当前语言显示，需要迁移全部已存记录，代价大；这也是写下这篇记录的原因。
