如果本次还启用了项目规则技能（如 p004-rules），它对位置、方向、尺寸、清晰度和人物模特的规定优先于本技能的默认做法；下面的写法只在项目规则没有规定时使用。

先 get_run_context，再按需调用 product-analysis 和 embroidery-rules（仅在本次选定时）。自动制作恰好满足授权张数，资料齐全后由后台提交；手动模式至少满足目标张数。用 save_suite_plan 保存方案，禁止调用任何生图接口。

## 1. 先写统一设计规格（locked）
规划之前写好逐项设计规格放进 locked：衣服款式与比例一条，每个个性化元素各一条（内容、穿着者视角位置、方向与阅读方向、相对大小、颜色、相邻关系，见 embroidery-rules）。再加一条“只出现在哪里、各有几个”。方向只用 product-analysis 的横向或纵向固定写法之一，位置同时写穿着者左右和正面视角下的画面位置。后台会把 locked 原样接在每张提示词后面，所以每条都是能单独看懂的完整句子；保存前按 embroidery-rules 的“保存前自查”读一遍。editable 写这套图允许变化的内容。

## 2. 规划套图结构
按用户要求覆盖主图、细节特写、生活场景、尺寸、衣服颜色、线色、字体等类型。参考原链接的展示逻辑，但不照搬构图。每张一个明确目的，避免两张几乎一样。

## 3. 每张 prompt 的写法
按以下顺序写完整：
1. **目的和画面**：场景、构图、机位、人物、光线。
2. **这张能看到什么**：哪些个性化元素在画面里，用画面位置描述，例如“名字在画面右侧那只袖子的袖口上方”（正面视角时穿着者左袖就在画面右侧）；不要只写“左袖”，生图模型会把它画到画面左侧。也写清哪些看不到（例如“背面视角，看不到胸前图案和袖口”）。
3. **本张的变化**：只能来自 editable，例如“衣服颜色：森林绿，名字线色：白色”。
4. **排除项**：例如“除规格列出的元素外，衣服上没有其他文字或图案；袖口名字不出现在胸前或衣身”。

prompt 不必重抄 locked（后台会附上），但不能与 locked 矛盾，也不要用“同上”。

## 4. 容易画坏的图
生图模型画好一件衣服的细节已经吃力；一张图里衣服越多、文字越多，细节越容易各画各的。
- **颜色展示图**：优先用平铺布样、色块或叠放衣服的局部展示颜色，最多一件完整展示图案。不要让每件衣服都重画胸前图案和袖口名字。确实需要多件时，件数不超过 4 件，并写明“每件只有颜色不同，图案缩小且完全相同，袖口细节不显示”。
- **尺寸图、线色图等信息图**：衣服只出现一件，角度和元素位置与主图一致，袖口元素留在袖口；文字面板只放必要的短词和数字（尺码、英寸、颜色名），不写长句。写明“只包含上述板块，不要额外添加细节拼图、小图、材质说明或品牌信息”，否则生图模型常自己加一排细节小图，小图里的袖口又会画成另一个样子。
- **字体选项图**：每个字体样本单独排列展示，不在一件衣服上叠多个名字。
- **特写图**：写明拍的是哪只袖子、哪个部位，元素方向与规格一致。

## 示例（只示范写法，内容按本次商品替换）
locked 的写法：
- “圆领加绒卫衣，宽松版型，罗纹袖口和下摆，衣身比例与参考图一致。”
- “胸前居中、领口下方约 8 cm：白色手写体 Max's 在上，下方是大号 varsity 字母 MOM，蜂蜜金毛巾绣填充、白色描边，金毛头像替换字母 O，真实机绣质感。”
- “穿着者左袖（正面视角时是画面右侧那只袖子）外侧、袖口罗纹上方约 4 cm：白色手写体名字 Amelia，文字沿袖子长度方向排列（文字基线与袖子平行），从肩膀一侧读起，字母顶部朝向手臂外侧；字高约为罗纹宽度的一半。”（方向要照参考图，从 product-analysis 的横向、纵向两种固定写法中选一种，这里只是示范纵向。）
- “一只实心黑色小脚掌，与名字在同一条基线上，紧挨在首字母 A 之前（按阅读顺序先看到脚掌，再看到名字），高度与名字字高相同。”（每张 prompt 写成“画面中从左到右依次是：黑色脚掌、Amelia”。）
- “整件衣服只有上述胸前图案、一个名字和一个脚掌；名字和脚掌只在穿着者左袖口，胸前和衣身其他位置没有名字或脚掌。”

颜色展示图的 prompt：“1:1 产品信息图，暖色木桌背景。上方标题 AVAILABLE COLORS。下方 8 块方形布样排成两行，每块是一种衣服颜色并在下方标注颜色名（Sand、Black、Navy…）。左侧放一件森林绿卫衣正面平铺，完整展示胸前图案；布样上不画任何图案和文字。除这件卫衣外，画面里没有其他衣服。”

尺寸图的 prompt：“1:1 尺寸信息图，浅米色背景。左侧一件森林绿卫衣正面平铺，角度与主图一致；名字和脚掌只在画面右侧那只袖子的袖口上方，画面左侧的袖子上什么都没有；衣服上用细线标注 WIDTH 和 LENGTH。右侧是简洁尺码表 S–5XL，两列数字，单位 inches。只包含这件卫衣和尺码表，不要额外添加细节小图或材质说明。衣身上不出现名字或脚掌。”

## 5. 选参考图
生图模型照着参考图画，比照着文字画准得多，所以参考图要选对：
- 每张最多四张，只选与这张最相关的；有客户成品图时优先使用。
- 画面里能看到袖口元素时，放一张袖口元素最清楚的参考图（袖口特写或成品图），让模型照着画方向和位置。
- 只是借用数据或排版思路的图（例如别家的尺码表、色卡长图），不要放进参考图，把数据直接写进 prompt；否则模型会照搬那张图的版式和多余内容。
- 参考图 ID 只能来自 input.references 和 product.referenceIDs。

## 6. 保存：分批、写短
模型单次回复有输出上限，一次写完很多张会被截断，方案就保存不了。
- 每张 prompt 约 200 字以内，只写这张特有的内容；统一设计规格由后台自动附加，不要在每张重复。
- 超过 6 张时分批保存：先用 save_suite_plan 加 `append: true` 暂存，每批不超过 6 张（第一批带上 locked 和 editable）；最后一批不带 append，提交剩余张数，后台合并后整体校验。
- 想清楚后直接调用保存，保存前不要再写长篇分析。
