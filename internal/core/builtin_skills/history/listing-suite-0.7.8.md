如果本次还启用了项目规则技能，以它为准。

本技能规划 Etsy、Amazon、Walmart 商品套图，用 save_suite_plan 保存，不调用生图接口。自动模式恰好满足 authorizedCount；手动模式至少满足 targetCount。不要擅自增加母版生成、重试或其他付费步骤。

## 1. 先定唯一设计，再分配图片
在 locked 中保存商品款式与比例、胸前整组、袖口整组及其唯一部位（规格项见 product-analysis；没有启用时也必须实际看图并确定）；在 notes 记录每组设计的固定参考图 ID 和来源。
- 每组一个固定短名，不能每张各排一次。
- 主图案用“图案只包含：……”列完整的有效设计；用“图案里没有：……”列明确去掉或禁止的特征。
- 具体厘米数需有来源。没有实测时写可确认的相对比例及项目上限，展示用决定不冒充真实规格。
- locked 与 editable 不矛盾；按上下文区分衣服配色和图案配色。editable 是全套允许范围，每张“本张变化”必须明确选定值，例如只选森林绿。
- 生图 prompt 写具体要求，不写内部代号或“执行店铺标准”。来源、未知项记录在 notes，但生图模型看不到 notes，必要视觉要求必须进 prompt 或 locked。

## 2. 逐图需求与平台
先在 notes 简要记录“序号—用户原要求—必须可见内容—设计参考—本张变化”。保留用户指定序号和顺序，不把第 2 张的细节要求挪到其他图就算完成；补充图片不取代用户明确要求。每张一个主要目的，相邻图片避免同构图、同景别、同内容。
目标平台看用户指令，商品来源链接不决定目标平台；没说时按 Etsy 的现有默认规划，不单独追问平台。
- Amazon 主图：沿用本应用默认的纯白背景、商品约占画面 85%、只展示商品、不加额外文字或道具的做法；具体品类或用户给出要求时先核对，不能把默认写法称为已核实的最新平台政策。
- Walmart 主图：沿用本应用默认的白底、正面完整商品、不加额外文字或道具；其他图可以规划场景和信息展示。
- Etsy 主图：主体居中并留裁切空间，可用用户允许的场景。

## 3. 按图分配参考图
- 参考图只能来自 input.references、product.referenceIDs 和 crop_reference 截出的图，最多四张；使用 sample 时为后台加在第 1 张的样板预留一个名额。
- 画出商品设计的图片不放含有其他款式、名字、宠物或配饰的参考图（款式对比图、多款陈列图、别家成品图）：写了“只取排列”生图模型也会照着画。场景、排列、姿势改用文字写；需要整件形状时只放同款、没有其他设计的图。
- 胸前可见时始终复用同一组参考图中的胸前设计依据，袖口可见时复用同一袖口依据。无关的色卡图、胸前局部图、场景图不要求有相同的参考集合。
- 设计参考放在前面。场景图只取场景，色卡只取颜色，不能让它们替换字形、主图案或袖口。角色写法和旧设计的处理见 image-prompting。
- 只借用尺寸、颜色名或排版数据的图不传给生图模型；核实后把必要数据写进 prompt，防止抄入错误商品。

## 4. 袖口句和局部样板
只在商品有袖口设计时应用本节，并设置 cuffEmbroidery: true；没有时设 false，不添加名字或图标的位置描述。

**袖口句**：确定唯一的一句，复制进每张袖口可见图的主体行。写明本张画面侧别、距接缝的位置、同行还是叠放、阅读顺序或上下关系、字形、图标与文字比例和方向。固定值来自 locked 和有效参考，不照抄示例名字。
- 同行示例：“画面右侧袖口接缝上方的平整袖筒中心，从左到右依次是图标、名字，二者同一基线，比例与固定袖口设计参考一致，文字基线平行袖口接缝。”
- 明确要求叠放时写“图标位于名字中点正上方，与名字中线对齐”，不同时要求同一基线或左右同行。
- P004 启用时直接用其姿势表，令前臂在画面里竖直向下、袖口接缝水平。
- 不能写“袖口不显示名字”来跳过已露出的袖口；整件正面图按袖口可见规划。只有真实裁切到其他局部或明确不可见机位，才不要求画袖口。
- 机位变化不允许将设计换到另一只实物袖子。

**细节样板 sample / useSample**
- 小细节出现在三张及以上且已有合适的交付图位时，选最清楚的一张标 sample: true，全套最多一张，通常为袖口近景；后台样板开头固定加入袖口局部要求，不能把胸前或整件图标作 sample。
- 不挤掉用户点名要的图片，不额外增加计费张数。没有合适图位时复用已有清晰设计依据，在 notes 记录原因。
- 样板要一次画准：先用 crop_reference 把最清楚、只含本次这一款的局部截出来（如对比图里本款的特写、成品图的袖口或袜口），样板 references 只放这张截图，最多再加一张同款、没有其他设计的整件图。prompt 开头写“以图1为底图修改：只改……（用户要求改的品种、名字、颜色等），图案、配饰形状和排版保持图1原样”。没有可截的清晰局部时，明确“图1只取某局部设计，不取整件构图”，不丢掉唯一的字形或图标依据。
- 后台用最高质量生成样板，并在其他图片开始前让 LLM 对照设计依据核对，不合格自动重画（最多 2 次）。
- 只有用户允许设计全新外观且规格足够确定时，才可无视觉参考规划样板。
- 袖口可见且存在该样板的其他图片标 useSample: true，references 最多三张；参考图行照常只列手动选择的图（图1、图2…），后台会把样板加为第 1 张并说明编号顺延。样板不能替代胸前依据。看不到该细节的图不标 useSample；样板本身不标 useSample。

## 5. 容易画坏的图
- **细节微距特写**：只展示指定设计与周围局部面料、线迹或缝线，不展示整件轮廓、领口、下摆和其他袖子全貌，并明确写出其他部位不画，因为后台仍会附加完整 locked。需要折叠时用局部折边体现。胸前文字是设计组成部分时保留，不能笼统写“除刺绣外没有文字”而删掉标题。
- **尺寸图**：最多一件商品，胸前和袖口仍按相同依据定位；尺寸数字、单位、尺码逐项来自来源。只包含指定商品与信息板块，不要额外添加细节拼图、品牌、工艺小图或未授权说明。
- **颜色图**：优先布样或色块，减少重复重绘复杂图案；用户没要求多件时最多一件完整商品。用户明确要求多件时逐件保持设计身份。
- **选项图只用有依据的选项**：线色、字体、衣服颜色、尺寸数量和名称均有来源，在 notes 记录；用户要求但缺资料时集中询问，不编造“全部”。
- **noProduct: true**：只适用于完全没有商品的线色卡、布样、字体样张；后台不加整件 locked，prompt 要自行写齐该图的数据与必要规则。有商品局部也不能标 noProduct。
- **主题元素与场景**：主题道具进入背景，不进入商品设计；写法见 image-prompting。默认只有主角穿本商品，其余人用不同颜色的无图案服装。
- 远景不能承担字体或针脚细节展示任务。

## 6. 写 prompt、分批保存、核对一遍
按 image-prompting 的短行格式写用途、场景、主体、参考图、画面文字（逐字）、本张变化和约束。超过六张时用 append: true 分批暂存，每批不超过六张；最后一批不带 append，合并后保存，locked 与 editable 在首批或末批提供。

想清楚后直接调用保存，保存前不要再写长篇分析。下面的清单只过一遍，只改发现的问题，不逐张重写或重新推敲：
1. 图片序号、用途、可见内容与用户要求对应；所有数据有依据。
2. 同一组合没有字形、间距、方向、比例或部位冲突；本张变化不与 locked 冲突。
3. 局部图写明不画其他部位；无商品图正确使用 noProduct；有袖口才写袖口句，有样板才标 useSample。
4. 参考图序号与 references 一致；旧图案没有盖过新要求，样板不挤掉胸前依据。
5. 修改已有方案时，只改用户点名的图片或共同规格及受影响图片；共同设计变更同步所有展示该设计的条目。
