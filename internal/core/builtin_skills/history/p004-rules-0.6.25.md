这是本店铺的项目规则（P004 生图规则），对本店铺所有套图都生效，用户指令提到 P004 时就是指这套规则。它和其他技能冲突时，以本技能为准：例如袖口文字方向不再照参考图，而按下面的袖口规则。

后台对未编辑的内置副本附加“项目固定规则”。把适用的固定句写入 locked 一次，每张 prompt 不得给出相反要求；不适用的部位在本张 prompt 写清画面外。自定义副本不保证有后台补充，不能省略用户修改过的有效要求。内部代号只用于规划，生图 prompt 使用下面的具体描述。

## 0. 先判断袖口有没有刺绣
第 4、5 条只适用于袖口有刺绣的商品。保存方案时必须用 save_suite_plan 的 cuffEmbroidery 说明：
- 用户指令、客户成品图或商品资料里袖口有名字、图标或图案时，cuffEmbroidery 为 true，照第 4、5 条写。
- 用户要求袖口不加设计（如“袖口不要加任何设计”），或指令和参考图里都没有袖口元素时，cuffEmbroidery 为 false。这时不要把第 4、5 条的固定句写进 locked，也不要在 prompt 里描述袖口刺绣的位置或方向；改为在 locked 写“两只袖子的袖口都是纯色罗纹，没有任何刺绣、文字或图案”。后台也会改为附加“两只袖子的袖口都没有任何刺绣、文字或图案”。
- 没有袖口刺绣时，只保留上述无设计声明，不写名字、图标或其位置、方向的正向细节，避免让模型凭空添加。

## 1. 人物模特
画面里出现的模特（成人、儿童、婴儿）只用欧美人。写 prompt 时直接写“欧美女性”“欧美男性”“欧美小孩”。
locked 固定句：“画面中的人物模特（含成人、儿童和婴儿）均为欧美人。”

## 2. 刺绣尺寸
- 每个刺绣图案的实际尺寸，长边和短边都不超过 25 cm。用户给了更小的上限时用更小的。
- 同一个图案在所有图片里实际尺寸和相对衣服的比例都一样；透视和远近只改变画面里看起来的大小，不改变它在衣服上的实际大小。
- 25 cm 是上限，不是每个图案的默认尺寸。有实测规格时把具体尺寸写入 locked；没有实测时，锁定参考图可辨认的整组宽高比及相对衣身、袖筒的比例，同时保留上限。不能把示例厘米数或视觉估计冒充真实规格；用户要求实测数据而资料缺失时集中询问。用户授权设计新尺寸时明确这是本次设计决定，不能称为原商品实测。
- 胸前标题、主体和配饰作为同一组合；标题字形、弧度、字距、标题与图案间距，以及组合内各元素比例都固定。袖口名字和图标同样成组锁定，不能只保证总宽度却改变内部排版。
locked 固定句：“所有刺绣图案实际尺寸长边和短边均不超过 25 cm；同一图案在每张图中的实际尺寸和相对衣服的比例保持一致。”

## 3. 卫衣胸前主刺绣居中
商品是卫衣时，胸前或衣身正面的主刺绣（文字、头像、装饰作为一个整体）以卫衣本体的垂直中轴线左右居中。卫衣斜放、折叠或不在画面中间时，刺绣跟着衣服中轴走，不向画面中间偏。
locked 固定句：“胸前主刺绣整体以卫衣本体的垂直中轴线左右居中，以服装本体中心为准，不以图片中心为准。”

## 4. 卫衣、连帽衫袖口刺绣（仅 cuffEmbroidery 为 true 时）
- 袖口刺绣只放在最终画面右侧那只袖子的袖口；画面左侧的袖子上没有任何刺绣。人物转身或换角度时，仍以最终画面右侧为准。
- 名字等文字的基线与这只袖口的接缝线平行，并且摆正：凡是看得见袖口刺绣的图，这只袖子都在画面里竖直向下（模特手臂自然下垂，平铺、挂拍时袖子顺着衣身垂下），袖口接缝水平，所以图标和文字在画面中也是水平的，不倾斜。不要把这只袖子斜放、横放或折起来，否则文字会跟着变斜或变竖，各图不一致。
- 整组刺绣在袖筒宽度的正中，从袖口接缝往上移到平整的袖筒上，不压在罗纹、接缝、折边或明显褶皱上。
- 画面位置不等于实物侧别：正面、未镜像时，穿着者左袖才在画面右侧。优先用能保持同一只实物袖子、画面右侧和文字水平的正面机位；不要为了满足画面右侧把刺绣换到另一只袖子，也不要翻转整张图导致文字镜像。
- 背面或转身图仅在该袖口确实不可见时写“看不到袖口刺绣”，不能一边露出袖口一边声称不可见。用户指定机位不能同时满足这些要求时，用 request_information 集中说明冲突，不用两套互相矛盾的位置描述强行保存。
locked 固定句：“袖口刺绣只在最终画面右侧那只袖子的袖口，这只袖子在画面里竖直向下、袖口接缝水平，文字基线与袖口接缝线平行，图标和文字在画面中水平摆正、不倾斜，整组位于袖筒宽度中心、接缝上方的平整处，不压罗纹或褶皱；画面左侧的袖子没有刺绣。”

## 5. 袖口小图标和名字的排列（仅 cuffEmbroidery 为 true 时）
袖口名字旁边有小图标（如脚掌、爱心）时，左右顺序必须每张都一样。因为文字沿袖口接缝排列，名字两端离肘部一样远，用离肘部或肩膀的远近来区分两端没有意义，生图模型会随机放左边或右边，所以只按阅读顺序写：
- 默认（用户没有特别说明，或只说“名字上刺绣脚掌”“名字旁加脚掌”）：图标与名字在同一条基线上，紧挨在首字母之前。
  locked 固定句：“袖口小图标与名字在同一条基线上，紧挨在名字首字母之前，按阅读顺序先看到图标、再看到名字，图标高度与名字字高相同，每张图顺序一致。”
- 用户明确说图标在名字后面：把“紧挨在名字首字母之前”换成“紧挨在名字末字母之后”。
- 用户明确说图标在名字正上方：写“图标位于名字中点的正上方（朝肘部方向），与名字中线对齐，间距约半个字高”。
- 同行布局逐张复制画面阅读顺序，例如“画面右侧袖口上，从左到右依次是：黑色脚掌、Amelia”；叠放布局逐张复制“图标在名字中点正上方、居中对齐”及有效间距，不额外要求同行。名字、图标形状、字形、大小和间距以本次设计为准，示例不是输入数据。
- 看得见袖口的每张图，都照 listing-suite 的“袖口句”写法写同一句话，同时写清同行还是叠放、左右顺序和文字在画面里的方向，并按那里的姿势要求安排手臂。只写顺序时，生图模型会在部分图里把图标放到名字上方，或把文字画成竖排。

## 6. 清晰度
整张图都要清晰，背景也清晰。单张 prompt 用“整张画面清晰”表达，不把“虚化”“景深”“浅景深”“柔焦”“散景”“bokeh”“模糊”“背景模糊”作为场景、光线或风格效果；需要突出主体时用构图和光线。下面固定句及后台相同内容中的否定说明是禁止这些效果，不与本条冲突，不再重复扩写。
locked 固定句：“整张图片清晰，背景同样清晰，不使用任何虚化、柔焦、景深或运动模糊。”

## 7. 套图规划
一个需求保持同一个商品设计和布局。用户允许的衣服颜色变化或选项展示可以规划，但图案配色、字形、整组关系与定位仍固定；未经要求不混入其他款式、包型或设计位置。

## 8. 规划检查的边界
P004 规定设计和构图，不代表程序已经测量或验收成图。按 listing-suite 检查逐图 prompt 与 locked、editable、参考图角色是否冲突；不得将“参考图已传入”“样板生成成功”写成细节已一致。当前规划工具不能执行成图质检、多母版调度或固定资产合成，不虚构这些步骤，也不为它们擅自增加付费图片。
