如果本次还启用了项目规则技能（如 p004-rules），它对位置、方向、尺寸、清晰度和人物模特的规定优先于本技能的默认做法；先消解冲突，再规划。

本技能规划 Etsy、Amazon、Walmart 商品套图。先 get_run_context，再调用本次选定的 product-analysis、embroidery-rules；写 prompt 时用已启用的 image-prompting。使用 save_suite_plan 保存，不调用生图接口。自动模式恰好满足 authorizedCount；手动模式至少满足 targetCount。不要擅自增加母版生成、重试或其他付费步骤。

## 1. 先定唯一设计，再分配图片
在现有 locked 中保存商品款式与比例、胸前整组、袖口整组及其唯一部位；在 notes 记录每组设计的固定参考图 ID 和来源。分析规格见 product-analysis；没有启用时也必须实际看图并确定这些信息。
- 每组一个固定短名；胸前文字与图案是一个组合，袖口名字与图标是另一个组合。锁定字形、弧度、字距、行序、间距、内部比例、方向、颜色、图案轮廓与数量，不能每张各排一次。
- 主图案用“图案只包含：……”列完整的有效设计；用“图案里没有：……”列明确去掉或禁止的特征。局部修改保留未要求修改的细节，不自动去掉配饰。
- 定位用衣服中轴、拉链末端、领口和袖口接缝等实物锚点；具体厘米数需有来源。没有实测时写可确认的相对比例及项目上限，展示用决定不冒充真实规格。
- locked 与 editable 不矛盾；按上下文区分衣服配色和图案配色。editable 是全套允许范围，每张“本张变化”必须明确选定值，例如只选森林绿；不能让模型在这张里从全套颜色中自由挑选。
- 生图 prompt 写具体要求，不写内部代号或“执行店铺标准”。来源、未知项、逐图要求记录在 notes，但生图模型看不到 notes，必要视觉要求必须进 prompt 或 locked。
- 当前 locked、editable 是字符串数组，notes 是文本。不要自造 designSpec、masters、visibleElements、reviewStatus 等未支持的工具字段或新资产 ID。

## 2. 逐图需求与平台
先在 notes 简要记录“序号—用户原要求—必须可见内容—设计参考—本张变化—核对条件”。保留用户指定序号和顺序，不把第 2 张的细节要求挪到其他图就算完成；补充图片不取代用户明确要求。每张一个主要目的，相邻图片避免同构图、同景别、同内容。
目标平台看用户指令，商品来源链接不决定目标平台；没说时按 Etsy 的现有默认规划，不单独追问平台。
- Amazon 主图：沿用本应用默认的纯白背景、商品约占画面 85%、只展示商品、不加额外文字或道具的做法；具体品类或用户给出要求时先核对，不能把默认写法称为已核实的最新平台政策。
- Walmart 主图：沿用本应用默认的白底、正面完整商品、不加额外文字或道具；其他图可以规划场景和信息展示。
- Etsy 主图：主体居中并留裁切空间，可用用户允许的场景。
每张用途写入 prompt；purpose、scene 字段本身不会发给生图模型。

## 3. 固定设计参考，按图选角色
- 参考图只能来自 input.references 和 product.referenceIDs，最多四张；使用 sample 时为后台追加的样板预留一个名额。
- 胸前可见时始终复用同一组参考图中的胸前设计依据，袖口可见时复用同一袖口依据。固定身份参考的相对顺序及作用说明，不要求无关的色卡图、胸前局部图、场景图也有完全相同的参考集合。
- 身份和设计依据优先于场景、颜色、姿势参考；设计参考放在前面。场景图只取场景，色卡只取颜色，不能让它们替换字形、主图案或袖口。
- “参考图”行逐张说明实际取用部位与角色；图号严格匹配 references 数组。同一张来源同时提供整件与细节时写清，不虚构已经裁切。
- 旧设计只能参考仍然有效的部分，明确不取哪些被修改的特征；新设计缺少视觉依据时在 locked 精确固定一次，不能称其为已验收母版。用户要求精确复制而关键细节不可辨认时先补资料。
- 只借用尺寸、颜色名或排版数据的图不传给生图模型；核实后把必要数据写进 prompt，防止抄入错误商品。

## 4. 袖口句、姿势和局部样板
只在商品有袖口设计时应用本节，并设置 cuffEmbroidery: true；没有时设 false，不添加名字或图标的位置描述。

**袖口句**：确定唯一的一句，复制进每张袖口可见图的主体行。写明本张画面侧别、距接缝的位置、同行还是叠放、阅读顺序或上下关系、字形、图标与文字比例和方向。固定值来自 locked 和有效参考，不照抄示例名字。
- 同行示例：“画面右侧袖口接缝上方的平整袖筒中心，从左到右依次是图标、名字，二者同一基线，比例与固定袖口设计参考一致，文字基线平行袖口接缝。”
- 明确要求叠放时写“图标位于名字中点正上方，与名字中线对齐”，不同时要求同一基线或左右同行。
- P004 启用时补其画面水平要求，令前臂在画面里竖直向下、袖口接缝水平，图标和文字水平摆正、不倾斜。只用能同时满足这些条件的姿势；坐姿时这只手放身体外侧，撑在臀旁坐垫或地面，不搭腿；举杯、拆礼物用另一只手。平铺、挂拍时该袖顺衣身竖直放置，不斜折到胸前。
- 不能写“袖口不显示名字”来跳过已露出的袖口；整件正面图按袖口可见规划。只有真实裁切到其他局部或明确不可见机位，才不要求画袖口；需要展示的细节不靠遮挡规避。
- 机位变化不允许将设计换到另一只实物袖子。保留 P004 的画面右侧规则，优先正面；确需的背面或转身与规则不兼容时先集中澄清，不写互相冲突的左右。

**细节样板 sample / useSample（现有单样板能力）**
- 小细节出现在三张及以上且已有合适的交付图位时，选最清楚的一张标 sample: true，全套最多一张。通常为袖口近景；后台样板开头固定加入袖口局部要求，因此不能把胸前或整件图标作 sample 来假装实现多母版。
- 不挤掉用户点名要的图片，不额外增加计费张数。没有合适图位时复用已有清晰设计依据，在 notes 记录无新样板的原因，不擅自改用户的图片要求。
- 样板优先使用清晰的局部设计参考，不为摆脱整件构图而主动丢掉唯一的字形或图标依据。只有整件参考时，明确“图1只取袖口局部设计，不取整件构图”；只拍局部、袖子竖直、接缝水平、文字摆正。
- 只有用户允许设计全新外观且规格足够确定时，才可无视觉参考规划样板；精确复现不能用无参考的自由生成代替。
- 袖口可见且存在该样板的其他图片标 useSample: true，references 最多三张；参考图行只列手动选择的图，后台会把样板加为最后一张并给出说明。袖口固定依据仍保留，样板不能替代胸前依据。看不到该细节的图不标 useSample；样板本身不标 useSample。
- 当前后台只等待样板文件生成，不验收其内容；样板失败或取消时可能继续生成其他图。不要把这描述为已具备严格拦截或保证一致；在 notes 记录此限制，不能写“已照样板画正确”。规划工具无法检查尚未生成的样板。

## 5. 容易画坏的图：按图片用途组织画面
以下沿用现有字段，不假装已经有资产合成或表格排版工具：
- **细节微距特写**：只展示指定设计与周围局部面料、线迹或缝线；不展示整件轮廓、领口、下摆和其他袖子全貌。需要折叠时用局部折边体现，不再拍一张整件折叠图。胸前文字是设计组成部分时保留其原有文字，不能笼统写“除刺绣外没有文字”而删掉标题。
- **尺寸图**：最多一件商品，胸前和袖口仍按相同依据定位；尺寸数字、单位、尺码逐项来自来源。只包含指定商品与信息板块，不要额外添加细节拼图、品牌、工艺小图或未授权说明。
- **颜色图**：优先布样或色块，减少重复重绘复杂图案；用户没要求多件时最多一件完整商品。用户明确要求多件时逐件保持设计身份，不能通过漏画图案或袖口凑一致。
- **选项图只用有依据的选项**：线色、字体、衣服颜色、尺寸数量和名称均有来源，在 notes 记录；用户要求但缺资料时集中询问，不编造“全部”。可选字体页没有依据时不强制补问。
- **noProduct: true**：只适用于完全没有商品的线色卡、布样、字体样张；后台不加整件 locked，prompt 要自行写齐该图的数据与必要规则。有商品局部也不能标 noProduct。
- **主题元素与场景**：主题道具进入背景，不进入商品设计。将用户场景写成可见条件，例如圣诞树和主题礼物；白底要求不加道具。户外聚会要有人物互动与聚会布置，人数按用户要求；没指定时可用 3 位或以上体现群体，不能只有一个人坐院子。默认只有主角穿本商品，其余人用不同颜色的无图案服装。
- 手、头发、道具不遮挡本张必须展示的胸前和袖口细节；远景不能承担字体或针脚细节展示任务。

## 6. 写 prompt、分批保存与逐图核对
按 image-prompting 的短行格式写用途、场景、主体、参考图、画面文字（逐字）、本张变化和约束；必要时补构图、材质、光线。不要重复整份 locked，但本张关键组合关系、定位和可见性要就近写清。
不设 250 字硬目标：完整设计关系、参考图角色、所有必要文字与数字优先；先删重复、无关修饰。超过六张时用 append: true 分批暂存，每批不超过六张；最后一批不带 append，合并后保存，locked 与 editable 在首批或末批提供。

保存前逐图读“最终会发给生图模型”的内容：本张 prompt + locked + editable + 有效项目固定规则，并按实际顺序检查参考图：
1. 用户要求与图片序号、用途、可见内容对应；所有数据有依据。
2. 同一胸前整组或袖口整组没有字形、间距、方向、比例或部位冲突；本张选定变化不与全套锁定冲突。
3. 局部图明确不画其他部位；无商品图正确使用 noProduct；有袖口才写袖口句，有样板才标 useSample。
4. 参考图没有让旧图案盖过新要求，样板不挤掉胸前身份依据，没有虚构母版或验收工具。
5. 修改已有方案时，只改用户点名的图片或共同规格及受影响图片；保留其他 prompt、图号、数据与参考图顺序。共同设计变更要同步所有展示该设计的条目，不能混用新旧版本。

以上是规划核对，不是成图验收。只报告已保存方案或缺失资料，不声称图片已一致。当前工具不支持生成后裁切比较、自动质检、多个新母版或局部合成；只有后端提供对应能力后才能执行这些步骤。
